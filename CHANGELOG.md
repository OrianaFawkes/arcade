# Arcade Changelog

A record of notable changes to this little place in an Empty Space.

## 2026-10-23

### Added
- Added optional, consent-gated Google Analytics to help understand how the arcade is used.
- Added analytics consent management and controls for changing the visitor's choice.
- Added a privacy notice explaining analytics and related data practices.

## 2026-10-22

### Added
- Added world focus management to make navigating the arcade easier as the screen grows.
- Added keyboard shortcuts to support world interaction.

### Improved
- Refined arcade world interactions and performance.
- Continued consolidating world behavior and improving the underlying structure.

## 2026-10-20

### Improved
- Improved arcade world support for mobile browsers.
- Continued refining how the world fits and behaves across screen sizes.

## 2026-10-19

### Changed
- Renamed the games to **Powers of Two** and **Proximity**.

### Improved
- Improved the Proximity board's responsiveness on smaller screens.
- Continued refining the presentation and interaction of the arcade world.

## 2026-10-17

### Added
- Expanded the arcade world and its supporting features.
- Experimented with an isometric presentation as part of exploring how the arcade could become a navigable space.

### Changed
- Restructured parts of the development environment and world implementation to support further iteration.

*The isometric view was an experiment rather than the final direction; the world later moved toward a top-down presentation.*

## 2026-10-02

### Added
- Began development of a Minesweeper-inspired game, initially released as a draft and later named **Proximity**.

## 2026-09-15

### Added
- Added an animation toggle for the original 2048 game, later renamed **Powers of Two**.

### Improved
- Added a GitHub Pages single-page application fallback so app routes can be opened directly or refreshed without losing navigation.

### Changed
- Updated the project license and README.

## 2026-09-14

### Added
- Published the initial version of Arcade, building on the existing 2048 game.
- Set up GitHub Pages deployment to make the arcade available on the web.
